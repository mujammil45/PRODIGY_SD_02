# PRODIGY_SD_02 – Number Guessing Game

## About
A Python-based Number Guessing Game developed as Task 02 of the Prodigy InfoTech Software Development Internship.

The program generates a random number between 1 and 100 and challenges the user to guess it.

## Features
- Generates a random number.
- Accepts user guesses.
- Displays hints (Too High or Too Low).
- Counts the number of attempts.
- Congratulates the user when the correct number is guessed.

## Technologies Used
- Python
- Random Module

## How to Run
1. Download the project.
2. Open the terminal.
3. Run the following command:

```bash
python number_guessing_game.py
```
